Plus Tard MCP — Documentation

Connectez votre agent IA (Claude, Cursor, n8n…) à votre compte Plus Tard pour planifier vos publications par conversation naturelle.

Vue d'ensemble

Le serveur Plus Tard MCP est un pont entre les agents conversationnels et l'API Plus Tard. Il expose 5 tools et 2 resources que l'agent peut invoquer pour valider une clef API, lister vos comptes, planifier un post, créer un nouvel utilisateur, ou consulter ses providers connectés.

Le serveur tourne en HTTP (transport « Streamable HTTP » du protocole MCP). L'authentification se fait par clef API personnelle, transmise par l'agent à chaque requête.

Prérequis

  • Une clef API Plus Tard active. Récupérable depuis votre espace utilisateur sur plus-tard.com.
  • L'URL du serveur MCP que votre administrateur vous a fournie. En local pendant le développement : http://127.0.0.1:8001/mcp/ (slash final obligatoire).
  • Un client MCP : Claude Desktop, Claude Code, claude.ai, ou MCP Inspector pour les tests.
Sécurité : votre clef API donne un accès complet à votre compte Plus Tard. Ne la partagez pas, ne la committez jamais dans un dépôt Git public, et révoquez-la depuis votre espace si vous suspectez qu'elle a fuité.

Connexion via Claude Desktop

Claude Desktop ne parle nativement que le transport stdio. On utilise l'utilitaire mcp-remote qui fait le pont avec un serveur HTTP.

Éditez le fichier de configuration de Claude Desktop :

~/Library/Application Support/Claude/claude_desktop_config.json (macOS)

claude_desktop_config.json 
{
  "mcpServers": {
    "plus-tard": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "http://127.0.0.1:8001/mcp/",
        "--header",
        "X-Api-Key:${PLUS_TARD_TOKEN}"
      ],
      "env": {
        "PLUS_TARD_TOKEN": "votre_clef_api_ici"
      }
    }
  }
}

Quittez complètement Claude Desktop (menu → Quit, pas juste fermer la fenêtre) puis relancez. L'icône MCP doit faire apparaître plus-tard avec ses 5 tools.

Le format X-Api-Key:${VAR} ne tolère pas d'espace après le :. C'est une particularité de mcp-remote.

Connexion via Claude Code (CLI)

terminal 
claude mcp add plus-tard \
  --transport http http://127.0.0.1:8001/mcp/ \
  --header "X-Api-Key: votre_clef_api"

Puis dans une session Claude Code, tapez /mcp pour vérifier le statut. Les tools sont ensuite disponibles dans la session.

Connexion via Claude.ai (web)

Si le serveur est exposé en HTTPS sur une URL publique, vous pouvez l'ajouter directement comme « connecteur personnalisé » dans claude.ai :

  1. Settings → Connectors → Add custom connector
  2. URL : https://votre-domaine/mcp/
  3. Header personnalisé : X-Api-Key = votre clef
Les URLs en localhost ne fonctionnent pas avec claude.ai. Pour tester rapidement avec un tunnel : ngrok http 8001.

MCP Inspector (debug)

L'outil officiel pour tester un serveur MCP en local :

terminal 
npx @modelcontextprotocol/inspector

Dans l'UI : Transport Streamable HTTP, URL http://127.0.0.1:8001/mcp/, ajoutez un header X-Api-Key: votre_clef_api, puis Connect. Vous verrez les onglets Tools et Resources et pourrez tout tester via formulaire.

Tools disponibles

validate_api_key GET

Vérifie que la clef API est valide et active.

Aucun paramètre. Retourne la date de création, d'expiration et de dernière utilisation de la clef.

Exemple d'utilisation : « Ma clef Plus Tard est-elle toujours valide ? »

list_accounts GET

Liste tous les comptes réseaux sociaux connectés à Plus Tard.

Aucun paramètre. Retourne pour chaque compte : nom, identifiant interne Plus Tard, identifiant externe sur le réseau social.

Exemple : « Quels comptes ai-je connectés à Plus Tard ? »

schedule_post POST

Planifie un post sur un seul réseau social.

  • provider enum requis — l'un de facebook, instagram, linkedin, twitter, tiktok, threads, bluesky, google
  • page_id string requis — pour Facebook/Instagram, l'id du sous-compte (vu dans list_accounts) ; pour les autres providers, le providerId du compte
  • planned_at date-time requis — date/heure UTC ISO8601 (ex. 2026-05-01T10:00:00Z)
  • text string optionnel — texte du post
  • image_posts array optionnel — URLs d'images ou vidéos. Chaque entrée peut être une chaîne (URL) ou {"path": "URL", "isStory": false}
  • twitter_params object optionnel — ex. {"is_thread": true, "max_chars_per_tweet": 280}
  • tiktok_params object optionnel — ex. {"privacy_level": "PUBLIC_TO_EVERYONE"}
Un appel = un réseau. Pour publier sur N réseaux, l'agent appelle ce tool N fois. Instagram exige au moins une image ou vidéo dans image_posts.

Exemple : « Programme un post Facebook sur ma page Boréales le 1er mai à 10h : "Hello le monde !" »

register_user POST

Crée un nouvel utilisateur Plus Tard et retourne une URL OAuth pour qu'il connecte ses réseaux.

  • email string optionnel
  • language string optionnel — fr ou en (défaut : fr)

L'URL OAuth retournée est valide 24h. L'utilisateur final doit l'ouvrir dans un navigateur pour connecter ses comptes.

get_user GET

Détail d'un utilisateur : ses providers connectés et leurs sous-comptes.

  • user_id integer requis

À utiliser typiquement avant schedule_post pour identifier le bon page_id.

Resources

Les resources MCP sont des données en lecture seule que l'agent peut consulter pour s'orienter. Dans Claude Desktop, elles apparaissent dans le picker de pièces jointes.

URIContenu
plus-tard://accounts Liste JSON de tous les comptes connectés (id, nom, identifiant externe).
plus-tard://users/{user_id} Détail JSON d'un utilisateur : email, langue, providers, sous-comptes.

Codes d'erreur

Le serveur remonte les erreurs de l'API Plus Tard avec un message lisible :

CodeCauseQue faire
401Header X-Api-Key absent ou clef rejetée par l'APIVérifier la configuration du client MCP, régénérer la clef si besoin
400Paramètres manquants ou invalides (ex. format de date, provider inconnu)Le message inclut error_description avec le détail
403Accès refusé (ressource n'appartenant pas au détenteur de la clef)Vérifier que la clef correspond bien au compte cible
404Ressource introuvable (user_id inconnu, etc.)Vérifier l'identifiant
409Conflit (ex. email déjà enregistré)Adapter la requête
502API Plus Tard injoignable ou en erreur 5xxRéessayer dans quelques minutes
504L'API Plus Tard a dépassé le délai de 10 secondesRéessayer

Workflows types

Planifier un post sur Facebook

  1. L'utilisateur dit : « Programme un post sur ma page Plus Tard le 1er mai à 10h : "Notre nouveau post !" »
  2. L'agent appelle list_accounts pour identifier le page_id de la page « Plus Tard ».
  3. L'agent appelle schedule_post(provider="facebook", page_id="...", planned_at="2026-05-01T10:00:00Z", text="Notre nouveau post !").
  4. L'agent confirme : « Post #456 planifié sur facebook le 01/05/2026 à 10h. »

Onboarder un nouveau client

  1. « Crée un compte Plus Tard pour client@exemple.com en français. »
  2. L'agent appelle register_user(email="client@exemple.com", language="fr").
  3. L'agent affiche l'URL OAuth retournée et vous invite à l'envoyer au client.

Vérifier une connexion bloquée

  1. « Pourquoi je ne peux pas planifier ? Ma clef est-elle bonne ? »
  2. L'agent appelle validate_api_key et affiche les dates d'expiration.
